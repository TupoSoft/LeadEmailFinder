# Machine Authentication Bruno Collection

This existing collection path is retained for compatibility. Machine authentication now accepts direct Bearer API
keys. The requests verify public health, rejection of missing credentials, and rejection of JWT-shaped legacy
credentials. Real API keys are generated by the checkout-owned development seed, stored privately under
`.dev/auth/`, and never committed.

The maintained service-client collection also checks active-key validation at `GET /v1/auth/api-key`, malformed-key
rejection, and human-only management. Run `corepack pnpm bruno:service-client-rejections` against this checkout's
owned disposable stack. Transaction and revocation behavior is covered by the API-key PostgreSQL integration tests
and `corepack pnpm test:mcp-server-live`.
